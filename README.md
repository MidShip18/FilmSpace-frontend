FilmSpace – Frontend
FilmSpace is a movie and TV discovery platform where users can explore movies and TV shows, view detailed information, rate titles, write reviews, manage their watchlist, and play a Movie Face-Off game.
Live Demo
- Frontend: https://film-space-frontend.vercel.app
- Backend: https://filmspace-backend.onrender.com
Features
- Movie & TV Discovery: Browse trending movies and TV shows.
- Search: Search for movies and TV series.
- Detailed Information: View details about movies and TV shows.
- User Authentication: Register and log in securely.
- Personal Ratings: Rate movies based on three categories:
  - Feel
  - Story
  - Impact
- Genre Ratings: Rate individual genres.
- Reviews: Write reviews and mark them as spoilers.
- Watchlist: Add and remove movies or TV shows from your watchlist.
- My Ratings: View your previously submitted ratings.
- Movie Face-Off: Compare popular movies in an interactive game.
Tech Stack
- React
- Vite
- JavaScript
- CSS
- Spring Boot (Backend)
- TMDB API
